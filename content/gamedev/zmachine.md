## Interpreters/VMs:

* Glulx – Similar to the Z-machine, but relieves several legacy limitations
* [Inform](/languages/inform6) – A computer language that can produce Z-machine programs
* [SCUMM](/gamedev/scummvm) – Script Creation Utility for Maniac Mansion by LucasArts, a graphical system similar to Z-machine
* [TADS](/gamedev/tads) – Like Glulx, made to address some of its limitations
* Motorola 68000 series – The base architecture used for virtual machines in Magnetic Scrolls' adventure games
* [Zeugma](https://www.linusakesson.net/software/zeugma/index.php) - A modern, highly optimised, open-source Z-machine implementation for the 6502 processor family. It is designed around a virtual memory model, where pages are retrieved on demand from an external storage resource, 512 KB in size, which must be preloaded with the game file.
