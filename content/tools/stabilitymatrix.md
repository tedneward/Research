### One click install and update for Stable Diffusion Web UI Packages
-   Supports:
    -   [Stable Diffusion WebUI reForge](https://github.com/Panchovix/stable-diffusion-webui-reForge), [Stable Diffusion WebUI Forge](https://github.com/lllyasviel/stable-diffusion-webui-forge), [Stable Diffusion WebUI AMDGPU Forge](https://github.com/lshqqytiger/stable-diffusion-webui-amdgpu-forge) [Automatic 1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui), [Automatic 1111 DirectML](https://github.com/lshqqytiger/stable-diffusion-webui-directml), [SD Web UI-UX](https://github.com/anapnoe/stable-diffusion-webui-ux), [SD.Next](https://github.com/vladmandic/automatic)
    -   [Fooocus](https://github.com/lllyasviel/Fooocus), [Fooocus MRE](https://github.com/MoonRide303/Fooocus-MRE), [Fooocus ControlNet SDXL](https://github.com/fenneishi/Fooocus-ControlNet-SDXL), [Ruined Fooocus](https://github.com/runew0lf/RuinedFooocus), [Fooocus - mashb1t's 1-Up Edition](https://github.com/mashb1t/Fooocus), [SimpleSDXL](https://github.com/metercai/SimpleSDXL/)
    -   [ComfyUI](https://github.com/comfyanonymous/ComfyUI)
    -   [SwarmUI](https://github.com/mcmonkeyprojects/SwarmUI)
    -   [VoltaML](https://github.com/VoltaML/voltaML-fast-stable-diffusion)
    -   [InvokeAI](https://github.com/invoke-ai/InvokeAI)
    -   [SDFX](https://github.com/sdfxai/sdfx)
    -   [Kohya's GUI](https://github.com/bmaltais/kohya_ss)
    -   [OneTrainer](https://github.com/Nerogar/OneTrainer)
    -   [FluxGym](https://github.com/cocktailpeanut/fluxgym)
    -   [Fizgig](https://github.com/shootthesound/Fizgig)
    -   [CogVideo](https://github.com/THUDM/CogVideo) via [CogStudio](https://github.com/pinokiofactory/cogstudio)
-   Manage plugins / extensions for supported packages ([Automatic1111](https://github.com/AUTOMATIC1111/stable-diffusion-webui), [Comfy UI](https://github.com/comfyanonymous/ComfyUI), [SD Web UI-UX](https://github.com/anapnoe/stable-diffusion-webui-ux), and [SD.Next](https://github.com/vladmandic/automatic))
-   Easily install or update Python dependencies for each package
-   Embedded Git and Python dependencies, with no need for either to be globally installed
-   Fully portable - move Stability Matrix's Data Directory to a new drive or computer at any time
